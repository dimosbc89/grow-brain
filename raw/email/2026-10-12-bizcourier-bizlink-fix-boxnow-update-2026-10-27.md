- 20:27 — ο Δήμος ζητά επιβεβαίωση για ενεργοποίηση BOX NOW Locker Delivery: (1) ενεργή η «Biz FF Last Mile Locker (BOX NOW) GR» στον λογαριασμό TANDEM; (2) ακριβές Service Code (166/167;) (3) χρήση του υπάρχοντος Sender CRM Code Ελλάδας; (4) αντικαταβολή και αν θέλει άλλο Service Code.
- 20:37 — BIZ IT: η υπηρεσία είναι **εμπορικά ενεργή** με είδος εργασίας **167**· προσθήκη Sender Profile με το ίδιο sender CRM και service code 167 στο BIZ LiNK Settings· στέλνει link με πλήρη οδηγό (bizurl.cloud) με απαραίτητα βήματα για να μπει η μέθοδος παράδοσης στο κατάστημα. Αντικαταβολή: μόνο ό,τι επιτρέπει η BOX NOW, «Pay on the Go» (πληρωμή με κάρτα από link SMS/Viber/email όταν το δέμα φτάσει στη θυρίδα). Η αλληλογραφία περνά στο customer support.
