# GROW Brain 🧠

Ο δεύτερος εγκέφαλος της GROW Agency: μία σελίδα ανά πελάτη, πρόσωπο, project και απόφαση, που το Claude κρατά ενημερωμένη από το Gmail, το Google Calendar και ό,τι ρίχνεις στο `inbox/`.

**Ξεκίνα από:** [[attention]] (τι τρέχει τώρα) · [[index]] (όλες οι σελίδες) · [[rules]] (πώς δουλεύεις) · `briefs/` (πρωινές ενημερώσεις)

## Πώς το χρησιμοποιείς
- **Ρώτα:** σε οποιαδήποτε συνομιλία με το Claude, «άνοιξε το grow-brain και πες μου τι εκκρεμεί με την Tandem» ή «γράψε απάντηση στη Νίκη με το ύφος μου».
- **Τάισέ το:** ρίξε αρχεία ή σημειώσεις στο `inbox/` (GitHub app στο κινητό ή Obsidian στο Mac).
- **Πρωινή ενημέρωση:** καθημερινές το πρωί, αυτόματα — διαβάζει τα νέα email και το ημερολόγιο, ενημερώνει τις σελίδες, γράφει το `briefs/ΗΜΕΡΟΜΗΝΙΑ.md` και σου στέλνει ειδοποίηση.

## Να το δεις ως γράφημα (Obsidian, Mac)
1. Κατέβασε το Obsidian (obsidian.md).
2. Terminal: `git clone git@github.com:dimosbc89/grow-brain.git ~/grow-brain`
3. Obsidian → *Open folder as vault* → `~/grow-brain`.
4. Settings → Community plugins → **Obsidian Git** → «Auto pull interval: 10» για να βλέπεις τις αλλαγές του Claude.
5. Graph view (⌘G): πράσινο = πελάτες, πορτοκαλί = leads, γαλάζιο = πρόσωπα, μωβ = ομάδα, ροζ = projects, κόκκινο = admin, κίτρινο = αποφάσεις, γκρι = πηγές.

Κανόνες λειτουργίας για το Claude: [[CLAUDE]].
