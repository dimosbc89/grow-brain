# Global Foods
> Εταιρεία τροφίμων/πρώτων υλών (άλευρα, μαγιά κ.ά.) με B2B εφαρμογή παραγγελιών app.globalfoods.gr («Globalapp, Built by GROW Agency»)· η GROW κάνει app, Google Ads, event content και γραφιστικά.

## Σε μια ματιά
- **Υπηρεσίες:**
  - Globalapp (app.globalfoods.gr): η εφαρμογή παραγγελιών, «Built by GROW Agency» ([[2026-08-06-globalfoods-paraggelia-39897]]). Είναι WooCommerce B2B, συνδεδεμένο με το Softone ERP μέσω custom plugin της GROW («Softone Connector for WooCommerce»), σε Plesk server· οι ώρες δρομολόγησης ανά πελάτη έρχονται από τα πεδία G1 / G1 Branch του Softone ([[2026-10-20-prohgoumenes-synomilies-claude]]).
  - Google Ads: report Μαρτίου–Σεπτεμβρίου 2026, σε συνέχεια report έως τέλη Φεβρουαρίου ([[2026-09-11-globalfoods-google-ads-report]]).
  - Event content: βιντεογράφος και live stories/posts στο event Pizza Detroit της 2026-10-06 ([[2026-10-02-globalfoods-live-projector-videographer]])· πρόταση videography ([[2026-10-08-globalfoods-videography-proposal]]).
  - Γραφιστικά: φυλλάδιο σεμιναρίου με συνταγές Detroit pizza ([[2026-10-05-globalfoods-fylladio-seminario-detroit]]).
- **Brands που εμφανίζονται:** Agugiaro & Figna, 5 Stagioni, Lemady ([[2026-10-05-globalfoods-fylladio-seminario-detroit]])· Unique Goods (έτοιμες πίτσες) ([[2026-10-02-globalfoods-live-projector-videographer]]).
- **Επαφές:** [[elpida-plavou]] (ρόλος ασαφής· παραλήπτρια report και πρότασης videography) ([[2026-10-08-globalfoods-videography-proposal]])· [[evi-psycha]] (Marketing, marketing@globalfoods.gr) ([[2026-10-02-globalfoods-live-projector-videographer]])· commercial@globalfoods.gr σε cc ([[2026-10-05-globalfoods-fylladio-seminario-detroit]]).
