# inbox/

Ρίξε εδώ ό,τι θες να μάθει ο εγκέφαλος: links, PDF, προσφορές, φωνητικά (ή απομαγνητοφωνήσεις), σημειώσεις από τηλεφωνήματα, screenshots.

Στην επόμενη πρωινή ενημέρωση (ή όταν πεις «κάνε ingest το inbox») το Claude τα διαβάζει, γράφει digest στο `raw/notes/`, ενημερώνει τις σελίδες και αδειάζει τον φάκελο.

Από το κινητό: GitHub app → grow-brain → inbox → Add file. Από το Mac: σύρε το αρχείο στον φάκελο μέσα στο Obsidian.
