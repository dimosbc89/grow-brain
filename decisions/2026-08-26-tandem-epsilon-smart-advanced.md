# Tandem: Epsilon Smart Advanced + API module, σύνδεση μέσω του bridge της GROW
> Η [[tandem-concept]] αγόρασε Epsilon Smart Advanced μαζί με το API module, και η GROW συνδέει το e-shop με το ERP μέσω του δικού της bridge.

## Αποφάσεις
**Τι αποφασίστηκε**
- Η Tandem αγοράζει Epsilon Smart Advanced **με** το API module (150€ + ΦΠΑ/έτος). Υπογραφή και πληρωμή 2026-08-26, με επωνυμία Tandem Concept ([[2026-08-28-tandem-epsilon-smart-offer-api]]).
- Η GROW δεν χρησιμοποιεί λύση της Epsilon για το e-shop: συνδέει μέσω του δικού της bridge, το οποίο είναι έτοιμο από τέλη Ιουλίου 2026, με βάση την τεκμηρίωση API της Epsilon ([[2026-08-28-tandem-epsilon-smart-offer-api]], [[2026-09-01-tandem-epsilon-eshop-bridge]]).

**Γιατί**
- Ο Δήμος ρώτησε ρητά αν η προσφορά περιλαμβάνει API access για άμεση σύνδεση e-shop ↔ Epsilon. Δεν το περιλάμβανε, άρα χρειαζόταν το επιπλέον module ([[2026-08-28-tandem-epsilon-smart-offer-api]]).
- «You can proceed ! we know the documentation we have build a bridge» ([[2026-08-28-tandem-epsilon-smart-offer-api]]).
